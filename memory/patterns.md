- "Last month X. Tonight Y." temporal-antithesis hooks (rule 7 variant). 2nd occurrence of the rule-7 family — the family is already a numbered rule, so it needs sharper enforcement in writer.md, not a new rule.
- **The rule 3 / rule 4 squeeze (structural, not a writing mistake).** Rule 3 demands a concrete reader outcome in the first line; rule 4 cuts any specific not traceable to a source. With no sourced facts file in the repo, every concrete outcome the writer invents ("chasing follow-ups", "the failed payment") is correctly killed by rule 4 — so the writer cannot satisfy 3 and 4 at once.
